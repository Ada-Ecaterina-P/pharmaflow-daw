# PharmaFlow

**Sistema Web Integral de Gestión de Stock, Fidelización de Clientes (CRM) e Integración CIMA para Oficina de Farmacia.**

> **Proyecto Intermodular — 2º Desarrollo de Aplicaciones Web (DAW)**  
> **Centro:** CESUR – Formación Profesional  
> **Autora:** Andrada Ecaterina Petrovici  
> **Tutor:** Gonzalo Pérez Crespo  

---

## Descripción

**PharmaFlow** es una plataforma web orientada a optimizar la operativa diaria de una oficina de farmacia comunitaria, centralizando el control de inventario (lotes y caducidades), la fidelización y seguimiento financiero de clientes, la gestión por roles y la consulta de medicamentos con la base de datos oficial **CIMA (AEMPS)**.
